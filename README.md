# Avan Market — локальная копия главной

Next.js, JavaScript и SCSS Modules. Главная доступна на `/` и `/ru` по-русски, на `/en` по-английски.

Все команды выполняются из единого корня репозитория — папки с этим README, `package.json`, `src/` и `public/`. Здесь же находятся Git-репозиторий, зависимости `node_modules/` и результаты сборки `.next/`. Настройки IDE и скриншоты проверок сохраняются локально и исключены из Git.

```bash
npm install
npm run dev
```

Для проверки production сборки:

```bash
npm run build
npm run start
```

Все изображения, аватары, SVG и шрифты оформления находятся в `public/`. Примеры сделок, отзывов и рекомендаций хранятся в `src/data/reference-content.json`. LIVE лента циклически движется из локального набора данных; счётчики рассчитываются из фиксированной UTC точки и времени локального сервера через `/api/time`, поэтому посетители видят одинаковые значения. Переходы в разделы, которые пока не скопированы, отключены.

Страница посвящена продаже скинов: в шапке оставлен пункт «Продать скины», в подвале — раздел продажи и юридическая информация. В блоке отзывов сохранены 12 отзывов с оценкой 5 из 5 со страницы https://avan.market/reviews, полученных 18 октября 2026 года: тексты без упоминания сервиса, исходные имена, аватары и ссылки на Steam-профили. Карточки в «Нас рекомендуют» ведут на YouTube- и Twitch-каналы из данных исходного сайта.

На главной в блоке `#inventory` работает оценка инвентаря из pricex2. Вставьте полный Steam Trade URL: браузер проверит ссылку и вычислит SteamID64 через BigInt. В серверный `POST /api/inventory` передаются только `steamId64`, `appId` и `currency`; токен обмена не отправляется и не сохраняется. Кнопки «Продать скины» в первом экране и меню, а также ссылки продажи в подвале ведут к форме.

Оценка не требует API-ключей или авторизации. Нужен публичный инвентарь Steam. Поддерживаются CS2 (730), Dota 2 (570), Rust (252490) и TF2 (440), поиск, сортировка, выбор найденных предметов, снятие выбора, смена ссылки и повторная загрузка. Сумма учитывает количество предметов, а предметы без известной цены показываются отдельно. При больших инвентарях карточки выводятся порциями по 100; сумма сразу считается по всему инвентарю, включая все страницы Steam. Оценка рыночная; авторизация, продажа и реальные выплаты к этому проекту пока не подключены.

Способы выплаты доступны после выбора скинов на сумму от 100 ₽ включительно: все 16 кнопок открывают соответствующую форму, «Сменить» возвращает список. Если сумма становится меньше порога, формы скрываются, а кнопки блокируются. Для других валют сервер переводит порог 100 ₽ по тому же курсу, что использован при оценке. Если курс рубля недоступен, выбор способа в другой валюте остаётся заблокированным. В подсказках каждого способа указана комиссия 1%. Для карт запрашиваются email, номер карты и ФИО; для СБП — email, российский телефон и банк; для банковского перевода — email, IBAN и ФИО; для PayPal и баланса — email; для Steam — email и профиль. Для каждой криптовалюты есть email, адрес кошелька и указание сети. Проверки адресов проверяют формат, а не существование кошелька или контрольную сумму блокчейна. Карты и IBAN проверяются с контрольной суммой.

В кнопке «Получить» показывается полная сумма выбранных скинов в текущей валюте. Комиссия обозначена только текстом «Комиссия 1%»: её сумма не рассчитывается и не вычитается. Блок «Об оценке инвентаря» удалён. Дата выплаты — через 7 дней от текущей даты по Москве (Europe/Moscow), на основе синхронизированного времени сервера. «Получить» проверяет поля и открывает экран сделки с тремя этапами, суммой, датой выплаты, полями бота и иллюстрацией подтверждения в Steam. Возврат к реквизитам сохраняет выбор и заполненные поля. До подключения реального обмена данные бота, код, номер и срок подтверждения показаны как ожидающие; кнопка подтверждения недоступна. Идентификаторы и таймеры не генерируются. Формы не отправляют заявки, не инициируют переводы и не сохраняют реквизиты в браузерное хранилище; введённое сохраняется только в памяти страницы при смене способа. Промокод, «Как получить быстрее» и ручной ввод суммы не отображаются.

Сервер получает инвентарь с `steamcommunity.com`, цены — с публичного [Skinport API](https://docs.skinport.com/items), курсы валют — с [ExchangeRate-API](https://www.exchangerate-api.com/docs/free). Изображения загруженных предметов идут с CDN Steam. Как в pricex2, для оценки берётся `mean_price`, при его отсутствии — `suggested_price`. Суммы хранятся в целых копейках/центах. Инвентарь кэшируется на 120 секунд, цены — на 5 минут, курсы — на час; одновременные одинаковые запросы объединяются. При HTTP 429 соблюдается `Retry-After`; без него пауза начинается с 60 секунд и увеличивается при повторных ограничениях. Браузер не отправляет запросы во время паузы. Для нескольких экземпляров Vercel поддержан общий Redis-кэш через `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` (либо `KV_REST_API_URL` / `KV_REST_API_TOKEN`). Без этих настроек кэш и пауза действуют в пределах одного процесса. Если Steam ограничивает IP Vercel, `INVENTORY_BACKEND_URL` и `INVENTORY_BACKEND_TOKEN` перенаправляют загрузку на отдельный сервер с защищённым API. Настройка и диагностика описаны в [docs/vercel-inventory.md](docs/vercel-inventory.md); пример переменных — в `.env.example`.

Если Skinport временно недоступен, используется последний успешный ответ. Для CS2 также сохранён резервный снимок 21 172 цен Skinport от 15 октября 2026 года в `src/data/inventory-prices.json`. В нём указаны время обновления данных источником (`updatedAt`) и время загрузки файла (`fetchedAt`). Архивные или сохранённые цены явно помечаются датой и предупреждением; для других игр без цен предметы остаются без оценки. Если курс выбранной валюты недоступен, отображаются суммы в USD с пояснением. Устаревшие цены не выдаются за актуальные.

Проверки локальной сборки: `python scripts/verify_local.py` и `python scripts/check_interactions.py` (нужен Playwright и Chrome). Скрипты `capture_reference.py`, `audit_layout.py`, `download_reference_assets.py` и `extract_reference_content.py` служат только для разработки и обращаются к исходному сайту.

Проверки оценки: `npm run test:inventory` — серверная логика без внешних запросов; `python scripts/check_inventory.py http://localhost:3000` — браузерные сценарии на ширинах 1440, 768 и 390 px и проверка HTTP-валидации. В браузерных тестах ответы оценки перехватываются только внутри теста; сам сайт всегда запрашивает реальные данные. Скриншоты проверки сохраняются в `screenshots/inventory/`.

Проверки форм выплаты: `npm run test:payout` — порог 100 ₽ и его эквиваленты в других валютах, поля и валидация каждого способа; `python scripts/check_payouts.py http://localhost:3000` — все 16 форм на ширинах 1440, 768 и 390 px, подсказки, возврат к списку, полная сумма без вычета комиссии, граница 100 ₽, блокировка при снятии выбора, дата +7 дней, экран сделки и возврат к форме, отсутствие отправки платёжных запросов. Скриншоты сохраняются в `screenshots/payouts/`.

`scripts/fetch_assets.py` — вспомогательный скрипт для ручного повторного снятия ресурсов и данных с оригинала. Для него нужны Python, `requests` и `beautifulsoup4`; при запуске он обращается к avan.market. Для запуска самой копии Python не нужен.
