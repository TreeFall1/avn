# Avan Market — локальная копия главной

Next.js, JavaScript и SCSS Modules. Главная доступна на `/` и `/ru` по-русски, на `/en` по-английски.

```bash
npm install
npm run dev
```

Для проверки production сборки:

```bash
npm run build
npm run start
```

Все изображения, аватары, SVG и шрифты оформления находятся в `public/`. Примеры сделок, отзывов и рекомендаций хранятся в `src/data/reference-content.json`. LIVE лента циклически движется из локального набора данных; счётчики рассчитываются из фиксированной UTC точки и времени локального сервера через `/api/time`, поэтому посетители видят одинаковые значения. Переходы в разделы, которые пока не скопированы, отключены.

На главной в блоке `#inventory` работает оценка инвентаря из pricex2. Вставьте полный Steam Trade URL: браузер проверит ссылку и вычислит SteamID64 через BigInt. В серверный `POST /api/inventory` передаются только `steamId64`, `appId` и `currency`; токен обмена не отправляется и не сохраняется. Кнопка «Продать скины», пункт оценки в меню и ссылка в подвале ведут к форме.

Оценка не требует API-ключей или авторизации. Нужен публичный инвентарь Steam. Поддерживаются CS2 (730), Dota 2 (570), Rust (252490) и TF2 (440), поиск, сортировка, выбор найденных предметов, снятие выбора, смена ссылки и повторная загрузка. Сумма учитывает количество предметов, а предметы без известной цены показываются отдельно. При больших инвентарях карточки выводятся порциями по 100; сумма сразу считается по всему инвентарю, включая все страницы Steam. Оценка рыночная; авторизация, продажа и реальные выплаты к этому проекту пока не подключены.

Сервер получает инвентарь с `steamcommunity.com`, цены — с публичного [Skinport API](https://docs.skinport.com/items), курсы валют — с [ExchangeRate-API](https://www.exchangerate-api.com/docs/free). Изображения загруженных предметов идут с CDN Steam. Как в pricex2, для оценки берётся `mean_price`, при его отсутствии — `suggested_price`. Суммы хранятся в целых копейках/центах. Инвентарь кэшируется на 30 секунд, цены — на 5 минут, курсы — на час; одновременные одинаковые запросы объединяются. Кэш находится в памяти процесса и сбрасывается при перезапуске. При масштабировании на несколько серверов его стоит вынести в общее хранилище.

Если Skinport временно недоступен, используется последний успешный ответ. Для CS2 также сохранён резервный снимок 21 172 цен Skinport от 15 октября 2026 года в `src/data/inventory-prices.json`. В нём указаны время обновления данных источником (`updatedAt`) и время загрузки файла (`fetchedAt`). Архивные или сохранённые цены явно помечаются датой и предупреждением; для других игр без цен предметы остаются без оценки. Если курс выбранной валюты недоступен, отображаются суммы в USD с пояснением. Устаревшие цены не выдаются за актуальные.

Проверки локальной сборки: `python scripts/verify_local.py` и `python scripts/check_interactions.py` (нужен Playwright и Chrome). Скрипты `capture_reference.py`, `audit_layout.py`, `download_reference_assets.py` и `extract_reference_content.py` служат только для разработки и обращаются к исходному сайту.

Проверки оценки: `npm run test:inventory` — серверная логика без внешних запросов; `python scripts/check_inventory.py http://localhost:3000` — браузерные сценарии на ширинах 1440, 768 и 390 px и проверка HTTP-валидации. В браузерных тестах ответы оценки перехватываются только внутри теста; сам сайт всегда запрашивает реальные данные. Скриншоты проверки сохраняются в `screenshots/inventory/`.

`scripts/fetch_assets.py` — вспомогательный скрипт для ручного повторного снятия ресурсов и данных с оригинала. Для него нужны Python, `requests` и `beautifulsoup4`; при запуске он обращается к avan.market. Для запуска самой копии Python не нужен.
